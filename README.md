# Apple Music Artwork Hider

You ever want to use Apple Music in a pbulic space but don't want to show potentially explicit album covers? This browser extension blurs or hides album artwork on the web version of [Apple Music](https://music.apple.com).

**NOTE: This does not work for Apple Music desktop or mobile applications.**

## Features

- **Show** — Display artwork normally (default)
- **Blur** — Apply a blur filter over all artwork
- **Hide** — Make artwork completely invisible

Changes apply instantly across the page, including the player bar and dynamically loaded content. Your preference is saved and persists across sessions.

## Browser Support

- Chrome / Chromium-based browsers (Google Chrome, Microsoft Edge, Arc) (Manifest V3)
- Firefox 109+ (Gecko)

## Installation

### Chrome (unpacked)

1. Go to `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked** and select this directory

### Firefox (temporary)

1. Go to `about:debugging#/runtime/this-firefox`
2. Click **Load Temporary Add-on** and select `manifest.json`

## Usage

Click the extension icon in your toolbar while on `music.apple.com` and select a mode (Show, Blur, or Hide).
